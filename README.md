# make.fun entry: u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209

This is a small program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: it writes a single line, the review an agent would post about its human, to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` when that is set (otherwise `OUTPUT_DIR`, otherwise `/output`), creating the folder if needed and printing the character count to stderr — the text is 1 to 280 characters and the file carries no trailing newline.
